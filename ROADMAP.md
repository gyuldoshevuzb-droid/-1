# Reborn production roadmap

## Milestone A — Combat foundation (implemented)
Native 3D locomotion, dash/i-frames, enemy physics, bosses, six weapon families, XP/upgrades, camera feedback and mobile controls.

## Milestone B — Survivor progression (implemented)
Meta shrine, permanent currency upgrades, achievements, weapon evolution, Arcade finale/overtime, 50-wave mode and boss rewards.

## Milestone C — Premium presentation foundation (implemented through v0.7)
Procedural skinned characters on `Skeleton3D`, stable bone/socket hierarchy, distinct hero identities, rigged monster archetypes, layered attack/cast/hit/dash animation, custom environment meshes, biome materials, water/fog/weather, weapon/ability VFX, original combat/UI audio, haptics, pause flow and a 3D menu showcase.

## Milestone D — Mobile cinematic / authored-content bridge (implemented through v0.14)
Asset Fusion for authored GLB characters and monsters, name-driven animation retarget bridge, external actor LOD, dynamic phone quality profiles, mobile post FX, layered material shaders, procedural grounding, directional hit reactions, boss telegraph animation phases, animation lookup caching, foliage/material performance budgets, orthographic top-down presentation, dark-fantasy grading and a production mobile UI/icon system.

## Milestone E — Release candidate
Real-device profiling, authored high-detail CC0/project-owned character replacements, expanded boss encounters, enemy pooling, save migration, onboarding, accessibility/localization, controller support, QA device matrix, signed Android AAB/APK and original store assets.

The project is structured so authored content can replace the procedural foundation without another gameplay rewrite.
